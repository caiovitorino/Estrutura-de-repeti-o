# 📘 Atividades Práticas de TypeScript — Estruturas de Decisão e Repetição

Repositório contendo a resolução das **30 questões contextualizadas no padrão ENADE** para a disciplina de **TypeScript**, sob orientação do **Prof. Celso Barreto**.

---

## 🎯 Objetivos de Aprendizagem

- **Interpretação de Condições:** Avaliação de expressões booleanas e previsão do fluxo de execução.
- **Estruturas de Decisão:** Construção de lógicas utilizando `if`, `else if`, `else`, `switch` e *operador ternário*.
- **Estruturas de Repetição:** Seleção e aplicação adequada de `for`, `while`, `do...while`, `for...of` e `forEach`.
- **Boas Práticas e Prevenção de Erros:** Prevenção de laços infinitos, eliminação de condições inalcançáveis e tratamento de valores de borda/fronteira.
- **Tipagem Estrita:** Uso de `strict: true` no compilador para garantir código seguro e previsível.

---

## 🛠️ Tecnologias Utilizadas

- **[TypeScript](https://www.typescriptlang.org/)** — Superset tipado do JavaScript
- **[Node.js](https://nodejs.org/)** — Ambiente de execução JavaScript
